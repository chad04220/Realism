## Realism 2.1.0 — save and load

The world can now be left and come back to.

### New
- **Save and load the whole world**: every voxel's material, temperature, damage and burn state, every loose body and how it is moving, parts and their charge, water, debris, the air (temperature, smoke, steam and flow), the player, tools, salvaged parts and the build on the workshop jig. A load reproduces the saved state exactly.
- **F5 / F9** quicksave and quickload.
- **Saved games page** (pause menu → *Save / load game*, title screen → *Load game*): name a save; every save is listed with its date, how long the world had been running and its size; load or delete. Overwriting and deleting ask for a second click.
- **Autosave** every 5 minutes (written in the background, so play barely pauses) and when you quit. **Continue** on the title screen picks up where you left off. The previous autosave is kept; if the newest is damaged the game loads the one before it.

### Reliability
- Saves are written to a temporary file, flushed to disk and then renamed, so a crash, a killed process or a power cut mid-save never damages the save you already had.
- Damaged, cut-off or newer-version saves are refused with a message and the world you're in is left untouched.
- Saves keep loading when materials are added or reordered in later versions.

### Also in this release
- A headless build and `--selftest` that run without a window or GPU, with CI on every push (from the 2.0 hardening pass): fixes to force integration, detonation performance, support-flood memory (512 MB → 16 MB), "new world" reset, blueprint loading and parts at coarse voxel sizes.
- `HANDOFF.md`: architecture, invariants, known issues and the roadmap.

### Install
Download `Realism-2.1.0-windows-x64.zip`, unzip it anywhere and run `Realism.exe`. Saves are kept in `%APPDATA%\Realism\saves`. Needs a GPU with OpenGL 4.3.

### Known issues
- The player walks through loose objects (next on the roadmap).
- No save thumbnails yet; no emergency save if the game crashes.
- Sound only on Windows.
