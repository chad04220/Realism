## Realism 2.3.0: faster rendering

Rendering work aimed at 8 GB cards like the RTX 3070, plus tools for measuring it.

### Faster rendering
- **Two-level empty-space skipping.** Rays jump across empty 4×4×4 cells as well as empty 16³ bricks. On the benchmark views this cuts ray steps per pixel by 15–50% and shadow steps by 25–47%.
- **Cached sun shadows.** A compute shader works out sunlight once per voxel and stores it in a texture, so pixels no longer trace their own shadow rays. It is only recomputed where solid matter appears or disappears, not when something is just burning or glowing.
- **Dynamic resolution**, on by default with a 60 fps target. While the GPU falls behind, the world renders below your render scale (down to half the window size), then climbs back. You can change it in Settings → Graphics or with `dynamic_resolution` / `target_fps` in `settings.cfg`.
- **No upload stalls.** World changes stream to the GPU within a 3 ms budget each frame, so a big blast spreads over a few frames instead of causing a hitch.

### Measuring
- **`Realism.exe --benchmark`** renders six fixed views and prints frame time and GPU time per rendering stage. It saves the table to `%APPDATA%\Realism\benchmark.txt`. Add `--size 1920 1080` to fix the resolution.
- **F3** now shows GPU time per rendering stage, the current render resolution and, on NVIDIA, video memory in use.

### Install
Download `Realism-2.3.0-windows-x64.zip`, unzip it anywhere and run `Realism.exe`. Needs a GPU with OpenGL 4.3.

### Known issues
- Building the shadow cache adds a moment to start-up on slow GPUs.
- The GPU speed-ups have been checked on a software renderer, not on real hardware. Please send `benchmark.txt` if something seems slow.
- Rigid bodies (loose objects) aren't stress-checked yet, and a heavy object resting on a structure doesn't load it.
